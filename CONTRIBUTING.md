# Contributing

Contributions are welcome. Please keep changes focused and include tests for
behavioral changes.

- Do not commit generated JAR files or large third-party binaries to Git.
- Put downloadable binaries in GitHub Releases.
- Preserve descriptor names and ordering unless a versioned schema change is
  intentional and documented.
- Include a reproducible test for concurrency, timeout, parsing, or descriptor
  correctness fixes whenever practical.
- Keep CDK1 compatibility work separate from CDK2 development.
- Preserve existing copyright and license headers.

For substantial changes, open an issue first to discuss scope and compatibility.
