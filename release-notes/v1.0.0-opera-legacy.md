# OPERA PaDEL bundle 1.00 - archival legacy release

> [!WARNING]
> This release is retained only for historical reproducibility. It contains a
> known concurrency defect that can intermittently produce missing descriptor
> values and incorrect zero values. Do not use it for new calculations. Use
> `v2.0.0-opera-fixed-cdk1` for current OPERA models.

## Identity

- OPERA bundle: `padel-full-1.00.jar`
- Embedded PaDEL application: 2.21
- CDK: 1.4.15
- Default OPERA descriptor schema: 1,444 columns excluding `Name`

## Known issue

With a positive `-maxruntime`, the legacy PaDEL worker starts descriptor
families for one molecule concurrently. Several families access a lazily
initialized shared CDK valence table. A concurrent first access can observe a
partially populated table, causing descriptor failures. PaDEL writes many of
those failures as blank CSV cells, while some autocorrelation failures can
propagate as false `0.0` values.
