# PaDEL CDK2 3.00 beta - CDK 2.13 engine

> [!IMPORTANT]
> This release uses CDK 2.13 and is a new descriptor-generation engine. The
> default profile retains the historical 1,444 descriptor names and order, but
> some values differ from the CDK 1.4 engine. Existing OPERA models must not use
> these values without retraining and validation.

This pre-release is intended for descriptor regeneration, future OPERA model
training, scientific validation, and integration testing.

## Main changes

- ports the PaDEL descriptor/fingerprint layer from CDK 1.x APIs to CDK 2.13;
- retains the OPERA-style command-line interface;
- preserves the default 1,444-column 1-D/2-D schema;
- provides an all-available 1-D/2-D profile with 1,544 columns;
- supports default 3-D and fingerprint profiles;
- uses deterministic molecule-level parallelism and bounded queues;
- replaces `Thread.stop()` with cooperative timeout handling;
- adds `-strict`, schema export, UTF-8 CSV output, and JSON provenance metadata;
- includes workarounds for CDK 2.13 valence initialization, 3-D builder
  concurrency, and invalid ring-template isotope records.

## Recommended invocation

```bash
java -Djava.awt.headless=true \
  -jar padel-full-3.00-cdk2.jar \
  -2d -removesalt -standardizenitro -detectaromaticity -retainorder \
  -threads 8 -waitingjobs 32 -maxruntime 60000 -strict \
  -dir input.smi -file descriptors.csv
```
