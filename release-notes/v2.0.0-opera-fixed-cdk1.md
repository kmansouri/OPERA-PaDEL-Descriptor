# OPERA PaDEL bundle 2.00 - fixed CDK1 compatibility engine

This is the recommended descriptor engine for current OPERA models. It repairs
the nondeterministic descriptor-loss issue in the historical bundle while
preserving the existing 1,444-column schema and numerical compatibility.

## Corrections

- safely initializes the legacy CDK valence table;
- evaluates descriptor families sequentially within each molecule;
- preserves parallel processing across molecules through `-threads`;
- implements positive `-maxruntime` with `ExecutorService`, `Future.get`, and
  cooperative cancellation;
- removes the obsolete use of `Thread.stop()`;
- corrects three scalar error-result paths;
- reports descriptor failures and timeouts at warning level.

## Compatibility

- Embedded PaDEL lineage: 2.21
- CDK: patched 1.4.15
- Descriptor schema: 1,444 columns excluding `Name`, unchanged
- Existing OPERA models: compatible; no retraining required
- Patched class target: Java 8
- Validated execution runtime: OpenJDK 21.0.11

Field-by-field regression testing found no semantic differences above `1e-10`
from a reliable legacy sequential baseline. The maximum absolute difference was
approximately `1.42e-14`, consistent with floating-point last-bit variation.

## Recommended invocation

```bash
java -Djava.awt.headless=true \
  -jar padel-full-2.00.jar \
  -2d -removesalt -standardizenitro -detectaromaticity -retainorder \
  -threads 8 -waitingjobs 32 -maxruntime 60000 \
  -dir input.smi -file descriptors.csv
```
