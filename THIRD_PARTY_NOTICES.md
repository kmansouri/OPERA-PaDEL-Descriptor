# Third-party notices

The historical PaDEL distributions and the modern CDK2 build include or derive
from third-party software. Preserve all embedded copyright and license notices
when redistributing binaries.

Important components include:

- Chemistry Development Kit (CDK)
- AMBIT2
- RapidMiner-derived classes in the legacy application
- Apache Commons CLI
- l2fprod Common Components
- Guava
- JGraphT
- JAMA
- XOM
- Swing Worker / Application Framework components

The archival PaDEL binary/source bundles contain their original license files.
The CDK 2.13 fat JAR retains CDK and bundled-dependency notices, and the CDK2
source package includes the corresponding license texts.
