This repository is a **mixed-license distribution**. No single repository-level
license overrides the notices contained in individual source files or bundled
third-party components.

- The upstream PaDEL-Descriptor project states that its original source was
  released as public domain, while portions using CDK, AMBIT2, RapidMiner,
  Apache Commons CLI, l2fprod, and other projects remain subject to their
  respective licenses.
- RapidMiner-derived source files retain GNU Affero General Public License
  notices.
- Chemistry Development Kit code and libraries retain their LGPL terms.
- Other third-party components retain their own copyright and license notices.
- New OPERA-PaDEL integration and modernization files are distributed under
  AGPL-3.0-or-later unless a file states otherwise.

Full license texts and notices are provided under `LICENSES/` and in the
corresponding GitHub release assets. Per-file notices control where they differ
from this summary.

redistributing the combined binaries should perform their own license review.
