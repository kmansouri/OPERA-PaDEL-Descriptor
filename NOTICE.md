# Notices and provenance

OPERA PaDEL-Descriptor is an independently maintained continuation and
modernization of PaDEL-Descriptor, originally developed by Chun Wei Yap.

Original publication:

> Yap CW. PaDEL-Descriptor: An open source software to calculate molecular
> descriptors and fingerprints. *Journal of Computational Chemistry*.
> 2011;32(7):1466-1474. doi:10.1002/jcc.21707.

This repository is not an official release of the original PaDEL author or the
Chemistry Development Kit project and does not imply their endorsement.

Related public project:

- https://github.com/cdk/PaDEL-Descriptor

Original PaDEL distribution page known to the maintainer:

- http://yapcwsoft.com/dd/padeldescriptor/

The historical `padel-full-1.00.jar` name refers to OPERA's all-in-one bundle,
not PaDEL application version 1.00. The embedded PaDEL application version is
2.21 and uses CDK 1.4.15.
